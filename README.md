# Polaris

**Roblox向け非公式ランチャー・FastFlag管理ツール**

Polarisは、Robloxの起動、FastFlagsの管理、設定の保存・復元などを簡単に行うためのWindows向けデスクトップアプリケーションです。

シンプルで使いやすいインターフェースを通じて、Robloxに関する各種設定を一元管理できることを目的としています。

> **注意：Polarisは非公式のコミュニティ製ソフトウェアです。Roblox Corporationとは一切関係ありません。**

---

## 主な機能

- **Robloxランチャー** — Place IDを指定してRobloxのゲームを起動
- **FastFlag管理** — FastFlagsの追加・編集・管理
- **プリセット管理** — 設定をプリセットとして保存・読み込み
- **バックアップ・復元** — 設定ファイルのバックアップと復元
- **設定管理** — アプリケーションの各種動作設定
- **ログ表示** — 動作状況やエラー情報の確認
- **モダンUI** — シンプルで見やすいデスクトップインターフェース

※機能はバージョンによって変更される場合があります。

---

## 動作環境

- Windows 10 / Windows 11
- Robloxがインストールされていること
- オンライン機能を利用する場合はインターネット接続

## インストール方法

1. GitHubの[Releasesページ](../../releases)を開きます。
2. 最新バージョンのPolarisをダウンロードします。
3. 必要に応じてZIPファイルを展開します。
4. `Polaris.exe`を起動します。

Windowsのセキュリティ警告が表示された場合は、ダウンロード元が公式リポジトリであることを確認してください。

## 基本的な使い方

### Robloxの起動

1. Polarisを起動します。
2. 起動したいゲームを選択、または追加します。
3. 対象のPlace IDを設定します。
4. PLAYボタンを押して起動します。

### FastFlagsの管理

1. FastFlag管理画面を開きます。
2. 追加・編集したいFastFlagを設定します。
3. 設定内容を確認します。
4. 適用操作を実行します。

設定を変更する前に、バックアップを作成することを推奨します。

### プリセット・バックアップ

設定をプリセットとして保存し、必要に応じて読み込むことができます。

また、バックアップ機能を利用することで、保存した設定を復元できます。

ただし、Robloxのアップデートなどによって、以前の設定が正常に動作しなくなる可能性があります。
